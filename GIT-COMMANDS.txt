Useful Git commands
===================

Check your changes
-----------------
git status
git diff

Save changes
------------
git add file-name          Stage one file
git add .                  Stage all changes in the current folder
git commit -m "message"    Commit staged changes
git push                   Push commits to the remote
git commit --amend         Amend most recent commit

Undo a commit
-------------
git reset --soft HEAD~1    Undo the last commit, keep changes staged
git reset HEAD~1           Undo the last commit, keep changes unstaged
git revert HEAD            Undo the last commit with a new commit (safe for pushed commits)

Branches
--------
git branch                 List local branches (* marks the current branch)
git switch branch-name     Switch to an existing branch
git switch -c branch-name Create and switch to a branch
git branch -d branch-name  Delete a merged local branch
git branch -D branch-name  Force-delete a local branch
git branch -m new-name     Rename the current branch
git branch -M new-name     Force-rename the current branch

Remote branches
---------------
git branch -a              List local and remote-tracking branches
git remote show origin     Show remote details and its default branch
git push -u origin name    Push a new branch and set its upstream

Sync with the remote
--------------------
git pull                   Fetch and integrate remote changes
git fetch                  Download remote updates without integrating them

Replace file-name, branch-name, name, and message with your own values.
